# 编译产物（以后都用这个）

在仓库根目录执行：

```text
powershell -File product\build.ps1
```

脚本会：

1. 调用本机 Go（优先 `C:\Program Files\Go\bin\go.exe`，否则 PATH 里的 `go`）
2. 生成 `product\hub.exe`、`product\hubd.exe`
3. 从仓库 `configs\` 同步示例 yaml 到 `product\configs\`

需要 **Go 1.24+**。只编译、不跑测试。若要先自检：

```text
go test ./...
go vet ./...
powershell -File product\build.ps1
```

`hub.exe` 与 `hubd.exe` 必须始终放在同一目录再分发。
