# Deckhand（发给别人用这个目录）

把**本文件夹整份**拷贝或打成 zip 即可，不必附带源码。

## 目录里有什么

| 文件 | 作用 |
|------|------|
| `hub.exe` | 唯一命令入口，给人或本地 AI 用 |
| `hubd.exe` | 后台进程，必须和 `hub.exe` **放在同一目录** |
| [CLI使用说明.md](CLI使用说明.md) | 命令、参数、退出码 |
| [配置说明.md](配置说明.md) | 要改哪些配置、放在哪、字段含义 |
| [编译.md](编译.md) | 从源码重新生成 exe（开发者） |
| `build.ps1` | 实际编译脚本 |
| `configs/` | 配置**模板**，复制到本机数据目录后再改 |

不要只拷 `hub.exe`。缺 `hubd.exe` 时命令会失败。

## 对方机器上怎么开始

1. 解压到任意目录，例如 `C:\Tools\Deckhand\`。
2. （推荐）把该目录加入 PATH，或以后用全路径调用 `hub.exe`。
3. 按 [配置说明.md](配置说明.md) 配置 SSH/COM（也可以先不写文件，直接 `user@内网IP`）。
4. 打开终端执行：

```text
hub run --json user@192.168.1.20 -- uname -a
```

第一次运行会自动创建 `%LOCALAPPDATA%\LocalAIHub` 并启动 `hubd.exe`。远端只要已有 sshd 或 COM，**不要装插件**。

给本地 AI 用时：在该产品里把 `hub.exe` 设为允许执行的命令。

更完整的命令表见 [CLI使用说明.md](CLI使用说明.md)。重新编译见 [编译.md](编译.md)。
