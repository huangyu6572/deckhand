# 编译产物

在仓库根目录执行：

```text
powershell -File scripts\build.ps1
```

脚本会调用本机 Go（优先 `C:\Program Files\Go\bin\go.exe`，否则 PATH 里的 `go`），生成 `product\hub.exe`、`product\hubd.exe`。

需要 **Go 1.24+**。只编译、不跑测试。若要先自检：

```text
go test ./...
go vet ./...
powershell -File scripts\build.ps1
```

`hub.exe` 与 `hubd.exe` 必须始终放在同一目录再分发。`product\` 只放 exe 和使用说明；示例 yaml 在仓库 `configs\`。

打 GitHub Release 用的 zip：

```text
powershell -File scripts\pack-release.ps1
```

产物：`dist\deckhand-windows-amd64.zip`。推 `v*` 标签或手动跑 Actions 工作流 `release` 会自动上传，见 [install.md](install.md)。
